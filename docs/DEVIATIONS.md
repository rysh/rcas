## 追加した仮定

### D-1　C3（制約の側に立証責任）：`r ∈ B` と `B.erase r ∈ C`

- **元の主張**：`cost` が包含について厳密単調で、`B` から原子 `r` を除いても許容なら、`B` は最小ではない。
- **追加した仮定**：
  1. `r ∈ B`
  2. `B.erase r ∈ C`（除いた後の制約も候補族に入っている。`C = Finset.univ` なら自動的に成り立つ）
- **なぜ必要か**：
  1. `r ∉ B` のとき `B.erase r = B` なので、「除いても許容」は「`B` が許容」と同じことになり、`B` が最小であることと両立する。反例：`not_minSufficient_of_erase_needs_mem`（`B = ∅`、`r = true`、`cost = card`、`Adm = True`。このとき `B` は最小十分）。「`B` から `r` を除く」という言い方が前提にしていることを明示しただけで、命題を弱めてはいない。
  2. 最小性は候補族 `C` に相対的なので、比較相手 `B.erase r` が `C` に入っていなければ何も言えない。
- **Lean**：`not_minSufficient_of_erase`、`MinSufficient.not_admissible_erase`

### D-2　K1（能力拡散の単調性）：`k 0 ≤ 1`

- **元の主張**：`k (t+1) i j = min 1 (k t i j + η * L t i j)`、`0 ≤ η`、`0 ≤ L` なら、`k` は各成分で単調非減少で、被覆は一度成り立てば保たれる。
- **追加した仮定**：初期能力が上限以下、`∀ i j, k 0 i j ≤ 1`。
- **なぜ必要か**：`k 0 > 1` だと最初の1歩で `min 1 _` により `1` まで切り下げられる。反例：`diffusion_needs_le_one`（`k 0 = 2`、`η = 0`。`k 1 = 1 < 2` で単調でない。さらに閾値 `θ = 2` の被覆は時刻 0 で成り立ち、時刻 1 で壊れる）。
- **補足**：時刻 1 以降は `k t ≤ 1` が自動的に成り立つので、この仮定が効くのは最初の1歩だけ。能力を `[0, 1]` に正規化しているという指示書の暗黙の前提を明示したもの。
- **Lean**：`diffusion_monotone`、`diffusion_cover_preserved`、およびそれを使う `eventually_selfManaging`（SM1）

### D-3　D2（依存の厳密減少）

指示書 §4.7 の注意書きどおり。

- **元の主張**：`D (t+1) < D t`。
- **追加した仮定**：
  - 1歩の形：`0 < p` と `0 < D t`（`dependence_succ_lt`）
  - `StrictAnti D` の形：`0 < p`、`p < 1`、`0 < D 0`（`dependence_strictAnti`）
- **なぜ必要か**：反例 `dependence_strictAnti_needs`
  - `p = 1`、`D 0 = 1`：`D 1 = D 2 = 0` で等号になる。
  - `D 0 = 0`（`p = 1/2`）：恒等的に `0` で等号になる。

### D-4　D5（時変の内面化確率）：`p t ≤ 1`

- **元の主張**：`p` が時変で `p t ≥ p_min > 0` でも D3・D4 が成り立つ。
- **追加した仮定**：`∀ t, p t ≤ 1`（D3 の仮定 `p ≤ 1` を時変版に引き継いだもの。`p` は確率なので自然な範囲）。
- **なぜ必要か**：上限がないと `1 - p t` が大きな負の値になり発散しうる。反例：`dependence_timeVarying_needs_upper_bound`（`p t = 3 ≥ 1/2` で `D t = (-2)^t`、0 に収束しない）。
- **補足**：証明が実際に使うのは `|1 - p t| ≤ 1 - p_min`、すなわち `p_min ≤ p t ≤ 2 - p_min` で、`p t ≤ 1` より少し弱い条件でも足りる。確率としての解釈を優先して `p t ≤ 1` を採った。

### D-5　FC1・FC2（選択肢の拡張）：`U` を固定

指示書 §4.9 の注意書きどおり。

- **元の主張**：情報集合も同時に更新され、`U(f | I')` と `U(f | I)` を比較していた。
- **追加した仮定**：`U : φ → ℝ` は一つの関数で、情報集合に依存しない。
- **なぜ必要か**：`U` が情報に依存すると、未来集合を広げても最大値が下がりうる。反例：`information_dependent_counterexample`（`F = F' = {()}`、更新前の `U = 1`、更新後の `U' = 0`）。
- 情報更新を入れる版は扱わない（指示書の指定）。
