# 仕様：利益配分をモデルに含めない理由（NoAllocation.lean）

## 著者の判断（2026-10-05）

著者のモデルに利益の配分はない。理由は2つある。

1. 配分が大きくてもアンダーマイニング効果がある。
2. 利益は変動するので、努力に見合った配分が必ずできるとは限らない。

これを受けて、次のように扱う。

- `Observable.lean`（OB1・OB2）は書き換えず、「著者のモデルの外にある、Holmström の枠組みとの対比」と位置づける。モジュールの説明文と対応表にその旨を明記する。
- 2つの理由を `RCAS/NoAllocation.lean` で形式化する。理由2は定理、理由1は前提として明示する。

## 理由2：利益の変動（定理）

記号：
- `q`：利益
- `c i`：メンバー i の努力に見合う額（`c` が何で決まるかは問わない）
- `s i`：配分

予算均衡は `∑ i, s i = q`。

- **NA1**（見合った配分ができる条件）：予算均衡で全員に見合った額以上を配れる ⇔ `∑ i, c i ≤ q`。
- **NA2**（できない時点）：予算均衡のどんな配分でも、`q < ∑ i, c i` なら `s i < c i` となるメンバーがいる。
  - 系：損失（`q < 0`）が出た時点では、誰かの配分が負になる。
- **NA3**（時間で見る）：利益の列 `q t` と見合う額の列 `c t` について、すべての時刻で予算均衡かつ全員が見合った額以上を受け取る配分の列が存在する ⇔ すべての時刻で `∑ c t ≤ q t`。利益が見合う総額を一度でも下回れば、どんな配分ルールでも、その時刻には誰かが見合わない。
- **NA4**（努力比例配分）：OB2 の努力比例配分では、同じ努力でも利益が違えば配分が違う（`e i > 0`、`e 0 + e 1 > 0` のとき）。配分は努力だけでは決まらず、利益の変動をそのまま受ける。
- 例：見合う額が各 3 の2人。利益が 10 → 4 と変動すると、4 の時点では誰かが 3 未満になる。

## 理由1：額によらないアンダーマイニング（前提）

`Motivation.lean` の2経路の力学を、配分額 `x t` に応じた低下 `γ (x t)` に一般化する（`x t = 0` は配分なし）。

`e (t+1) = e t + β·1[verbal t ∧ autonomous] − γ (x t)·1[x t > 0]`

- **前提**：配分額がいくらでも `γ x ≥ γMin > 0`（`x > 0`）。これは前提であり、EMPIRICAL に置く。
- **NA5**：承認的フィードバックのない時刻に配分があれば、額によらず `e (t+1) ≤ e t − γMin`。
- **NA6**（比較）：この力学の軌道は、低下を一律 `γMin` とした `engagementPath` の軌道以下に収まる。額を大きくしても、低下が `γMin` より小さくなることはない。
- **NA7**：配分がまったくなければ、承認的フィードバックだけで `e` は単調非減少（SDT2 と同じ）。

## 範囲外

- `c`（見合う額）・`γ`・`γMin` の値と形、利益の確率モデル。
- 配分が努力を直接増やす経済的効果（Holmström 型の誘因）。著者のモデルには配分がないので扱わない。
